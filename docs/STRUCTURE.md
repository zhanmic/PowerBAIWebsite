- Hero section with app name and tagline
- Key features (3-4 cards)
- Screenshots
- Download CTA button
- Quick benefits list

### 2. Features (`features.html` or `pages/features.js`)
- Detailed feature descriptions
- Use cases

- Benefits for each feature

### 3. Getting Started (`getting-started.html` or `pages/getting-started.js`)

- System requirements
- Prerequisites

### 4. Documentation (`docs.html` or `pages/docs.js`)

- Config file examples
- FAQ section
- Troubleshooting tips
- Video tutorials (if available)

### 5. About (`about.html` or `pages/about.js`)
- What is BI Automation Interface?
- Problem it solves
- Who it's for
- Developer info

- Support email
- GitHub issues link
- Community links
- Feedback form (optional)
