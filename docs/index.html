Key Features

🔄

Bulk Dataset Refresh

Trigger dataset refreshes across multiple workspaces using workspace name prefixes. Save hours of manual work.

📊

Export Refresh History

Export comprehensive refresh history reports with customizable lookback periods and filtering options.

⚙️

Config File Management

Easily manage workspace prefixes with JSON configuration files. Create, edit, and organize your presets.

🧹

Cleanup Automation

Clean up user-created refresh reports only. It does not delete anything from your workspaces or datasets.
